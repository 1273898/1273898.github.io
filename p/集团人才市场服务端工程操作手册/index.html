简介

人才市场服务平台是一个基于Spring Boot构建的人才信息管理系统，旨在为企业和人才之间搭建高效的信息交流与匹配平台。该系统提供了全面的人才信息管理、项目信息管理、公司信息管理等功能，帮助企业更有效地发现和管理人才资源。系统整体划分为控制层、业务层、持久层和横切层，各层之间职责清晰、依赖有序，符合高内聚、低耦合的设计理念。通过将接口处理、业务逻辑、数据操作及通用功能（如日志记录与权限校验）独立分层，项目实现了逻辑清晰、结构稳定、易于扩展与维护，方便后续功能升级与团队协作。

架构分层

层级 模块示例 职责 特点
JWT认证 "com.zjsz.uims.authentication.**" 校验用户身份 通行条件
控制层 CompanyInfoController PersonInfoController PersonProjectPerformanceController ProjectInfoController TempProjectInfoController TempProjectPersonInfoController DTO参数校验 → 调用业务层 → 装配VO返回 接口入口
业务层 PersonInfoService TempProjectInfoService CompanyInfoService 封装核心业务逻辑，数据处理与调用 具体功能实现
持久层 PersonInfoMapper PersonProjectPerformanceMapper ProjectInfoMapper TempProjectInfoMapper TempProjectPersonInfoMapper 负责与数据库交互，包括增删改查操作 数据交互
AOP切面 GlobalExceptionHandle 将公共代码解耦，如日志，全局异常处理 高复用可拓展
数据存储 mysql 存储系统数据 常用存储
  • JWT认证：负责拦截请求获取token校验用户身份
  • 控制层：负责定义接口，接受处理参数，调用Service，封装返回值
  • 业务层：包括各业务Service接口，处理核心业务逻辑
  • 持久层：数据库交互层，定义mapper接口，配置XML文件，主要是用Mybatis-Plus简化单表查询，复杂查询写入XML
  • AOP切面：提供公共功能和服务，实现日志、权限校验等通用功能，解耦公共代码

技术栈

后端框架

  • Spring Boot 2.x：快速开发框架
  • Spring MVC：Web层框架
  • MyBatis-Plus：ORM框架，简化数据库操作
  • Spring Security + JWT：安全认证与授权

数据库

  • MySQL 8.0：关系型数据库
  • Redis：缓存数据库，提升系统性能

中间件

  • Nginx：反向代理和负载均衡
  • RabbitMQ：消息队列，异步处理

开发工具

  • Maven：项目构建工具
  • Git：版本控制
  • IDEA：开发IDE

接口文档

人才管理接口

  • GET /api/person/list：获取人才列表
  • POST /api/person/add：添加人才信息
  • PUT /api/person/update：更新人才信息
  • DELETE /api/person/{id}：删除人才信息

项目管理接口

  • GET /api/project/list：获取项目列表
  • POST /api/project/create：创建新项目
  • PUT /api/project/update：更新项目信息

公司管理接口

  • GET /api/company/info：获取公司信息
  • POST /api/company/update：更新公司信息
